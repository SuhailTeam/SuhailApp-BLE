## Method notes

- **Headline** (time-to-first-spoken-word) pools every valid turn across participants into one
  sample for the median + IQR; per-participant medians are shown above as a consistency check.
- **Quantiles**: inclusive / linear interpolation (Excel `QUARTILE.INC` == NumPy `linear` ==
  Hyndman & Fan type 7), so a reader can reproduce them in a spreadsheet.
- **Task success**: moderator `success` column when present, else derived (the intended command
  for the task was eventually routed correctly); the source is shown in parentheses.
- **Recoveries per task** = turns beyond the first for that task instance.
- **SUS**: standard 10-item scoring, (Σ adjusted items) × 2.5 → 0–100; mean across participants.
- Latency per command = the on-device `total_s` median (captured on Mentra Live); until device
  CSVs are present these cells read needs-device / needs-participants.
